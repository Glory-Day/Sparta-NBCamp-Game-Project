## 소개

> 내일 배움 캠프 Unity 11기의 최종 프로젝트 기간 진행한 팀 프로젝트입니다. '다크 소울' 시리즈, '블러드 본' 등 소울류 장르에서 영감받아 진행한 조선 시대를 배경으로 한 3D RPG 게임을 제작하였습니다.

## 개발 환경

- **OS**: Windows Platform
- **Engine**: Unity 2022.3.62f2
